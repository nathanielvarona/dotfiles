# Installation

Bootstrap and apply steps for this dotfiles repository.

## Quick Start

### macOS / Linux

```bash
sh -c "$(curl -fsLS https://get.chezmoi.io)"
chezmoi init --apply nathanielvarona
```

### Windows (PowerShell)

```powershell
iex "&{$(irm 'https://get.chezmoi.io/ps1')}"
chezmoi init --apply nathanielvarona
```
